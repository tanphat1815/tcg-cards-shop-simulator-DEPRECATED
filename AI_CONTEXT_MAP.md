## 🏗️ Architecture Overview
The project is a Web-based TCG Shop Simulator using Vue.js, Vite, and Matter.js for physics. It follows a modular structure organized into "Communities" of related logic.

2. **Game Logic (`game-handle`)**: Manages the main game loop, interactions, and event processing.
3. **Physics & Interaction**: Driven by Matter.js, handling collisions and character movement (now migrating to Isometric).
